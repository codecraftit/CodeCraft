About CodeCraft

My name is Okunloye Mercy Oluwadarasimi, and CodeCraft is my personal brand as a front-end web developer. I am currently a student in my second year studying web development, and I created this website as part of my SIWES (Students Industrial Work Experience Scheme) training here in Nigeria.

I started learning web development because I have always been curious about how websites work behind the scenes — from the layout you see, to the colors, to the way buttons respond when you click them. What started as curiosity has slowly turned into something I actually enjoy doing, even on the days it gets frustrating (and trust me, it gets frustrating).

Right now, my main focus is on HTML, CSS and JavaScript basics — things like building layouts with flexbox, styling pages properly, and slowly getting comfortable with how the web actually works. I am not an expert yet, and I do not pretend to be one. This website itself is proof of that: it is simple, it is not perfect, but it is something I built with my own hands, and I am improving small small.

My goal with CodeCraft is to keep building real projects like this one, learn from my mistakes, and one day be confident enough to build full websites for real clients and businesses. For now, this is me documenting the journey, one project at a time.
